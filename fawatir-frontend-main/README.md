# fawatir-frontend

Frontend application for the **FawatirAI ERP** project, built with `Next.js`, `React`, `Tailwind CSS`, and `TypeScript`.

---

##  File Architecture

```text
src/
├── app/          # Application routes
├── components/   # Reusable UI components
├── hooks/        # Custom React hooks
├── lib/          # Utilities & API services
├── styles/       # Global styles
└── types/        # Shared TypeScript types
public/
package.json
```
